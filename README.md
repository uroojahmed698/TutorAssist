Tutor Assist

AI-Powered Tutoring Assistant

Tutor Assist is a full-stack web application designed to help tutors manage students, analyze student work, and generate personalized progress reports for parents. It streamlines repetitive administrative tasks so tutors can spend more time focusing on their students' learning.

Features
Tutor Authentication: Secure account registration and login using Supabase.
Student Management: Add, view, update, and delete student information.
AI Progress Reports: Generate personalized, parent-friendly student progress reports.
Student Work Analysis: Upload worksheets and assessments for AI-powered analysis.
Personalized Feedback: Identify student strengths, areas for improvement, and recommended next steps.
Grade Management: Calculate final grades based on weighted tests and assignments.
Report Management: Save and access student information and previous reports.

Technologies Used: React - Frontend development
Python - Backend development
FastAPI - Backend API
MongoDB - Student and tutor data storage
Supabase - User authentication
Ollama - Locally hosted AI models
JavaScript - Application functionality

Running the Project Locally: The application requires both the frontend and backend to run.
Clone the repository.
Install the frontend dependencies.
Configure the required environment variables using the provided .env.example.
Set up the Python backend and its dependencies.
Configure the required database, authentication, and Ollama services.
Start the frontend and backend servers.
Refer to the project configuration files for the specific setup requirements.
